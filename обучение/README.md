# Обучение

Проект в первую очередь **лаборатория платёжного контура**, не «сдать тестовое». ТЗ — набор жёстких сценариев. Цель этапа — понять, почему без идемпотентности, эскроу и «таймаут ≠ отказ» ломаются деньги и ключи.

Сервисы и нагрузка наращиваются: **один покупатель → несколько сразу → шторм**. После кода — обязательный разбор в файле этапа.
