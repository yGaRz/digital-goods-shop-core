# Обучение

Проект в первую очередь **лаборатория**: учимся, почему без аккуратной оплаты, удержания денег и правила «долго молчит ≠ отказал» ломаются деньги и ключи. ТЗ — набор жёстких сценариев, а не «просто закрыть галочки».

Сервисы и нагрузка наращиваются: **один покупатель → несколько сразу → шторм**. После кода — обязательный разбор в файле этапа (простым языком).
